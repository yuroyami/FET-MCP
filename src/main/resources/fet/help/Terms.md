Mode: terms. This mode was developed with suggestions from the users of FET from Finland, but it might be used in other countries as well. The data has a number of terms and a number of days in each term. The total number of days must be the product of these two numbers. The week begins with the first term's days, continues with the second term, and so on.

Instructions for the terms mode (Finland).

Last modified on 2 July 2025.

The terms mode was suggested, chronologically, by these users: mathmake and mikkojoo. You can follow a forum discussion about it here: https://lalescu.ro/liviu/fet/forum/index.php?topic=4387.0

The main ideas:

There are nTerms (say 5) terms, and nDaysPerTerm (say 5) days each. So there are nTerms x nDaysPerTerm (say 5 x 5 = 25) FET days. The terms are in order, one after another, and one day after another.

In this mode you can use some additional constraints referring to terms.
